# Eye 👁 — 이미지 공지·스캔 강의자료 읽기 도우미

화면낭독기로는 읽을 수 없는 **이미지 공지**(인스타그램·카카오톡·웹의 카드뉴스, 포스터 캡처)와
**스캔본 강의자료 PDF**를 글자로 바꾸고, 핵심 정보부터 음성으로 알려 주는 파이썬 앱입니다.

## 처리 흐름

| 단계 | 이미지 공지 | 강의자료 PDF | 코드 |
|---|---|---|---|
| 입력·알림 | 캡처하거나 공유한 카드뉴스·포스터 | 사이버캠퍼스에 새로 올라온 강의자료 | `eye watch`, `eye inbox` |
| ① 감지 | 새 캡처가 생기면 자동 실행, 글자가 있는 이미지인지 판단 | PDF에 글자 정보가 있는지 확인, 없으면 "스캔본" 알림 | `detect.py` |
| ② 전처리 | 확대, 대비 보정, 배경 장식 줄이기 | 페이지별 이미지로 나누기, 기울기·그림자 보정 | `preprocess.py` |
| ③ 글자 인식 | 글자마다 내용·위치(좌표)·확신도를 저장 | (같음) | `ocr.py` |
| ④ 읽는 순서 | 가까운 글자를 블록으로 묶고 위→아래, 왼→오른쪽 정렬. 여러 단·표는 칸 단위로 | (같음) | `layout.py` |
| ⑤ 정보 추출 | 행사명·일시·장소·신청 방법·마감 찾기, 날짜·시간 형식 통일 | 제목·문단·번호 목록·표 구분, 쪽 번호·머리말 제외 | `extract.py`, `dates.py`, `layout.py` |
| ⑥ 검증 | 확신도 낮은 글자, 두 가지로 읽히는 날짜(예: `12/03`) 찾기 → 요일로 판단, 안 되면 "확실하지 않음" | (같음) | `verify.py` |
| ⑦ 출력 | 음성 안내: 핵심 정보 먼저, 불확실 항목 선택, 전체 읽기, 원래 게시글 연결 | 글자가 들어간 PDF·텍스트로 저장, 불확실한 글자 표시, 차례대로 읽기 | `output.py`, `cli.py` |
| 피드백 | 사용자가 고른 날짜, 고친 글자를 기록해 추출·검증 규칙을 고침 | (같음) | `feedback.py` |

## 설치

```bash
# 1) OCR 엔진과 한국어 데이터
sudo apt install tesseract-ocr tesseract-ocr-kor espeak-ng   # Ubuntu/Debian
brew install tesseract tesseract-lang                          # macOS
# Windows: https://github.com/UB-Mannheim/tesseract/wiki 에서 설치 (Korean 선택)

# 2) 앱
pip install -e .          # 또는 pip install -r requirements.txt
eye check                 # 준비 상태 확인
```

## 사용법

```bash
# 이미지 공지 읽기: 핵심 정보를 먼저 읽고 번호 메뉴를 띄운다
eye image 캡처.png --url https://instagram.com/p/xxxx
#   1 핵심 정보 / 2 불확실 항목 선택 / 3 전체 읽기 / 4 원래 게시글 열기 / 0 끝내기

# 강의자료 PDF → '강의자료.읽기용.pdf'(글자 들어간 PDF)와 '강의자료.읽기용.txt'
eye pdf 강의자료.pdf -o 읽기용폴더

# 새 캡처·다운로드한 PDF를 자동으로 읽기 (기본: 스크린샷·사진·바탕화면·다운로드 폴더)
eye watch ~/Pictures/Screenshots ~/Downloads

# 자동으로 읽어 둔 것 중 안 읽은 공지 듣기
eye inbox

# 학습 기록 보기 / 지우기
eye feedback
eye feedback reset
```

공통 옵션: `--no-voice`(글로만 출력), `--rate 200`(말하기 속도), `--json`(image/pdf 결과를 JSON으로).

예시 파일 만들기: `python examples/make_samples.py` → `examples/sample_poster.png`, `examples/sample_scanned.pdf`

### 출력 예

```
행사명: 2026 진로 특강
일시: 2026년 12월 3일 목요일 오후 2시부터 오후 4시까지
장소: 학생회관 3층 대강당
신청 방법: 구글폼 forms.gle/abc123
마감: 2026년 11월 30일 월요일
```

## 동작 방식 요약

- **두 가지로 읽히는 날짜**: `12/03`은 12월 3일 또는 3월 12일. 옆에 요일 `(목)`이 있으면 요일이 맞는 쪽을 고르고,
  없거나 둘 다 안 맞으면 "확실하지 않음"으로 표시한 뒤 메뉴 2번에서 직접 고를 수 있습니다.
  사용자가 일/월 순서를 두 번 이상 더 많이 고르면 기본 순서가 바뀝니다.
- **확신도 낮은 글자**: 기본 60% 미만 또는 숫자 사이에 `O`, `l` 같은 헷갈리는 글자가 있으면 표시합니다.
  전체 글에서는 `[?글자]`로, 음성에서는 "확실하지 않은 글자"라고 읽습니다.
  고친 글자는 다음부터 자동으로 고치고, 표시가 자주 맞았는지/틀렸는지에 따라 기준 확신도(40~80%)를 조정합니다.
- **읽는 순서**: 단어를 줄로 묶고(가로 간격이 크면 다른 단), 줄을 블록으로 묶은 뒤 XY-cut으로 위→아래, 왼→오른쪽 순서를 정합니다.
  세 칸 이상 반복되는 줄은 표로 보고 행 단위로 읽습니다.
- 데이터(학습 기록, 안 읽은 공지, 자동 결과)는 `~/.eye/`에 저장됩니다. `EYE_HOME` 환경변수로 바꿀 수 있습니다.
